# Stack Forge — four-way review, and the plan that comes out of it

Geometry · Painting · UI · Load-Save, reviewed independently on `feat/forge-save-architecture`,
2026-08-06. Every claim below was proven by extracting the shipped function and running it in node, or
verified directly against the source. Where the reviews overlap they agree, and the overlaps are the
worst defects.

---

## The three findings that explain most of the last two days

### A. The carve was TOP-ONLY by default, and never persisted  *(FIXED)*
`carveCuts = { top: true, side: false, front: false }`, absent from `snapshotProject`. Every load and
every one of ~20 `recarve()` sites rebuilt the model as the **top silhouette extruded through the full
box height** — side and front art contributed nothing. Press ⬛ Carve front and it is right; reload and
it is gone. Owner's rule 4 is "their COLLISIONS carve the block"; that was opt-in and reset on reload.

**Worse: `carve.js`, the DOM-free core with 19 green tests, already defaulted to all three.** The tested
carve and the shipped carve disagreed and no test could see it, because `stack-forge.html` never loads
`carve.js`.

### B. Not one colour tool writes the model
There are exactly four writes to a `vcol` buffer in the file: `.vox` import, procedural tree, the carve,
and a throwaway local in `renderGridView`. **Every artist colour operation writes `voxEdit`**, which
`buildModel` stopped reading. `buildFaces` reads the "was this painted" flag from `voxEdit` and the
colour from `vcol` — different stores — so the flag fires and the colour does not: painting a voxel red
makes its walls flip from the side-sheet art to the flat column colour, in 3D and in the bake. Measured.

### C. Half the geometry edit tools are dead, and they poison the ones that work
🧹 Clear layer, both Mirrors, brush erase and ➕ Add all write `voxEdit` `'del'`/rgb — no effect. Worse,
brush and Add read `curFilled` from the overlay, so the first no-op erase makes **every retry on that
voxel return false**. Only marquee-select → Delete writes `VOL` and works.

## Cross-cutting: the same quantity computed in many places

| quantity | sites |
|---|---|
| the carve | `carve.js:70` (tested, unused) · `stack-forge.js:461` (shipped, untested) |
| slice → face resample | `sliceMask` (majority) · overlay `drawImage` (nearest) · dim box `projImg` (**bilinear**) |
| ink threshold | `INK_A=40` · `>0` (.vox) · literal `40` (wand) · `>20` (eyedropper) |
| the palette | **four** independently-derived quantisers; `palMap` keyed in one, applied after another |
| voxel delete | `deleteSelection` (VOL, works) · five `voxEdit 'del'` sites (dead) |
| footprint centre | `foot/2` (render, bake) · `(foot-1)/2` (tree) · `oy+bh/2` (barrel) |
| the unit id | `activeUnitId` (autosave) · `$('uid').value` (bake, download, roster selection) |
| camera/light | `m.config` (global, last-save-wins) · every pack's own copy |
| the roster | manifest ∪ shipped — never unions `proj:*`, though decor unions `decor:*` |

**A tool whose preview and output are computed by different code cannot be trusted, and this one has
three resamplers, four palettes and two carves.**

## Plan

### Phase 0 — done today
- `carveCuts` defaults to all three cuts and is saved/restored. *(A)*
- `bakeDecor` `ReferenceError` (a regression from the bake-tilt commit) fixed via module-scope `bakeElOf()`.
- Save modal no longer names `content/units/<faction>.units.json` — a file the tool only ever READS.
- ESC no longer mutates the model; DEL cannot reach geometry from behind a dialog.
- Main window is always the geometry view; baked sprites moved to their own preview modal.

### Phase 1 — stop losing work  (do first, in this order)
1. **One undo stack.** `volHistory` (VOL) and `undoStack` (voxEdit) are two 60-deep histories with the
   keyboard split across them: Ctrl+Z → geometry, Ctrl+Y → paint, ↶ button → paint, tooltip says Ctrl+Z.
   Accidentally mirror, press Ctrl+Z, and it reverts an unrelated earlier delete — **compounding** the
   damage. Merge to one history of `{VOL, vcol, PAINT}`; Ctrl+Z/Y and both buttons drive it.
2. **Faction switch out of the Terrain set writes decor over a unit's WIP.** It clears `editingDecor`
   but not the editor and never re-anchors `activeUnitId`; the next click autosaves the decor snapshot
   into `proj:<activeUnitId>`. One dropdown change from the Tree-1 wipe, backwards.
3. **A WIP-only slot looks empty** (`suppliedUnits()` never unions `proj:*`), so clicking it opens the
   Save modal and overwrites the WIP. Union `proj:*` into the roster — this also restores the missing
   card and the clash warning.
4. **Deleting a WIP is undone by the autosave it armed** 500 ms earlier, and leaves `atlas:`/`model:`/
   descriptor behind so the card still reads "supplied ✓".
5. **Ship still deletes when the disk read fails.** The merge only holds when the fetch succeeds; a 404
   leaves `onDisk = {}` and writes anyway. Abort on unreadable disk. `shipDecor`'s catch is silent.
6. **"Save geometry" over a shipped unit destroys it** — it writes a `geometryOnly` stub that fails
   `validatePack`, so `loader.js` drops the unit from the game. Refuse to ship an invalid descriptor.
7. **`doAutosave` returns nothing and fails quietly** — the store holding the carving is the one save
   that still lies. Return `{ok}`, route failures through `saveFailed`.

### Phase 2 — make preview equal output
8. **Load `carve.js` and delete the inline carve.** `<script src="carve.js">` before `stack-forge.js`;
   `buildVolume` calls `carve({foot, layers, box, slices, cuts})`. Nineteen existing tests become a
   real gate and finding A becomes unrepeatable. Same for `select.js`.
9. **Route every geometry edit through the VOL path** (`pushVol` + `V[k]=`), exactly as
   `deleteSelection` does. Delete `applyVoxEdits` and the `'del'` sentinel. *(C)*
10. **Paint architecture** *(B)*: bake wall art into `vcol` at carve time — which kills the Tier C
    divergence by construction, since `collectVox`/`.vox` are per-voxel and cannot carry per-face art.
    Add `PAINT` beside `VOL`. One writer `setVox(part, k, rgb)`. One quantiser cached per
    `(part, paletteN, palEpoch, carveEpoch)`, read by the grid, `buildFaces` and `collectVox`.
    Persist `vcol` + `PAINT`.
11. **One resampler for the overlay.** Draw the geometry overlay *from the mask*, not by blitting the
    image — a 1px antenna currently survives in the overlay and is deleted by the carve, so you align
    against a picture that lies. Disable smoothing in `projImg`.
12. **All four alpha thresholds reference `INK_A`.**

### Phase 3 — placement correctness
13. **FRONT slice is mirrored in y** between the carve and both the Front grid view and the geometry
    overlay. Exactly one of the four facings disagrees; side and back are consistent. Fix in ONE place
    and add a test asserting `AX.front`, `GEOAX.front` and the cut index agree.
14. **Barrel**: cannot protrude (`bx1` clamps to `foot-1` for every reach since the box became the
    grid), is half a voxel off-centre, and ignores `z0`.
15. **Bake and orbit frames are sized from the BODY footprint** — a 96-foot turret on a 64 body has
    18.4px clipped off the baked sprite, and the orbit clips too so you cannot see the damage.
16. **Decor bakes at one elevation and records another** — `bakeDecor` computes `sp` from `state.el`
    but renders at `bakeElOf()`. The unit path fixed this; decor was missed.
17. **`bodyTopLayer` re-carves the body uncached on every refresh** and misses hand edits, so the
    turret mount height is computed from the un-edited hull.
18. **`carveCache` keyed on `{foot, layers}` only** — no epoch. Correct only because ~20 sites remember
    to call `recarve()`. Put `carveEpoch` in the key.

### Phase 4 — UI honesty and layout
19. **One persistent status bar**, four zones, one writer each: identity (`activeUnitId`, flagging a
    diverged `#uid`) · model (voxels + dims) · freshness (`not baked` / `baked ✓ 45° 2×` /
    `⚠ EDITED SINCE BAKE`) · persistence (WIP · Manifest · Disk, one dot each). This subsumes eleven
    contradictory status strings, the stale "✓ Baked" after every invalidation, and answers "which
    store did that write". Transient results go to a toast, never the bar.
20. **`wipDirty` set by real mutations only** — today a capture-phase click listener marks the project
    dirty and runs a full snapshot when you toggle Guides or press Cancel.
21. **Delete or wire the phantoms**: `#gridResetAll` (no handler, advertises a destructive wipe),
    `#smooth`, `#sharp`, `#decRevolve`, `Set camera for bake` (prints a message, stores nothing).
22. **Fix the left-panel note** that still says clicking a card saves — it describes the behaviour that
    destroyed a unit.
23. **`#unitGrid` `min-height:60px`** with ~100px cards: the roster is a 60px slit and extras append
    last. Raise to two rows; collapse the manifest block instead.
24. **One modal contract** — ESC + backdrop + focus-first-field + `inert` background, from one shared
    `openModal`/`closeModal`. Five modals currently have five different dismissal behaviours.
25. **Confirm `⏭ Open and DISCARD`** — one click, no confirm, no undo, in the classic misclick slot.

### Phase 5 — durability
26. **Atomic ship writes**: `dest.tmp` + `os.replace`. A crash mid-`json.dump` truncates the one file
    carrying every unit. Reject `data is None` — it currently writes literal `null` and returns `ok`.
    Keep a `.bak`. With `--lan`, refuse POST from non-loopback peers.
27. **Version the formats and read the version.** `version: 2` is written and read nowhere; no manifest
    carries one, though inline-atlas → IndexedDB was a real format break.
28. **Delete/rename a unit** — no path exists, so a mistake ships forever; `atlas:`/`model:` leak.

---

## Order

Phase 1 first: those are the ones that cost work. Then 8 (load `carve.js`) — it is one line of HTML and
it converts an entire tested module into a gate, which is what stops Phase 2 and 3 regressing. The
status bar (19) is the highest-value UI item and subsumes five separate complaints.
