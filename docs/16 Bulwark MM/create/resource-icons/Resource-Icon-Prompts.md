# Resource icon prompts (Grok)

36 icons, one per resource (9 planets × 4 tiers). Each prompt is self-contained: paste it into Grok Imagine as is.
Save each result as the file named under it (512 × 512 PNG or larger), so the game can pick it up by id.

**Shared style (already inside every prompt):** Square 1:1 game inventory icon for a stylized sci-fi strategy game. One single object, centered, three-quarter view, filling about 70% of the frame, with a clean, instantly readable silhouette. Painterly semi-realistic rendering with crisp edges, soft key light from the upper left and a thin rim light. Plain dark slate background (#0d121a) with a soft circular vignette. No text, no letters, no border, no frame, no hands, no table, no extra objects.
