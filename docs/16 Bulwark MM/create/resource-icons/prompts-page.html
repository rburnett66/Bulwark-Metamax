Bulwark resource icon prompts

One Grok Imagine prompt for each of the 36 resources: 9 planets, four tiers each. Every prompt already carries the shared style, so you can paste it as is. Save each image under the file name on its card so the game can find it.

Shared style, inside every prompt

Square 1:1 game inventory icon for a stylized sci-fi strategy game. One single object, centered, three-quarter view, filling about 70% of the frame, with a clean, instantly readable silhouette. Painterly semi-realistic rendering with crisp edges, soft key light from the upper left and a thin rim light. Plain dark slate background (#0d121a) with a soft circular vignette. No text, no letters, no border, no frame, no hands, no table, no extra objects.

Tier finish

Common is matte with a faint blue glow; uncommon has a soft sheen and gold glow; rare gets inner light, small motes and a coral-red glow; epic is the most radiant and detailed, with a green glow. These match the tier colours the game already uses.
