Each model is a list of simple parts — boxes, cylinders, extruded side or top profiles, lofted cross-sections — with one material key per part. Parts merge per material, so a unit is a handful of draw calls and can be instanced. Ortho 4-up renders front, side, top and rear like the reference sheet.
